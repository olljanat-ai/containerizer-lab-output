# Sandbox identity provider

WSO2 Identity Server at **https://containerizer-idp.sandbox.lab/** (console: https://containerizer-idp.sandbox.lab/console, user `admin`). Generated by containerizer
from the apps in this repository; do not edit, the next run rewrites this folder. Docs: https://containerizer.eu/sandbox-idp/

| For apps | URL |
| --- | --- |

| SAML 2.0 metadata (entity id `https://containerizer-idp.sandbox.lab`) | https://containerizer-idp.sandbox.lab/identity/metadata/saml2 |
| WS-Federation metadata | https://containerizer-idp.sandbox.lab/wsfed-metadata/FederationMetadata/2007-06/FederationMetadata.xml |

## How it is applied

`kustomization.yaml` (included by the Flux root Kustomization) deploys the server (`server.yaml`), its
External Secret (`secrets.yaml`), network policies and a CoreDNS override (pods resolve
`containerizer-idp.sandbox.lab` to Traefik in the cluster). CronJob `cz-idp-sync` applies `sync/idp.json` and
`sync/apps__*.json` to the server through its REST API every 5 minutes and removes applications it created
that are no longer listed.

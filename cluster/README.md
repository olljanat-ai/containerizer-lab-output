# Cluster kit

Cluster-level settings for every app in this repository, for whoever runs a real cluster (the sandbox's Flux
does not apply this folder). Generated by `containerizer org`; the next run rewrites it.

- `secret-store.yaml`: the `ClusterSecretStore` the apps' ExternalSecrets read (docs/external-secrets.md).
  Each app's own read access to its keys is in its `gitops/flux/tenant.yaml`.
- `verify-images.yaml`: Kyverno admits only images signed with your key, from the apps' image paths, in the
  namespaces Containerizer manages (label `app.kubernetes.io/managed-by: containerizer`). Put your cosign
  public key in it.
- `audit-policy.yaml`: the API server's audit policy (NSA/CISA), `--audit-policy-file`.

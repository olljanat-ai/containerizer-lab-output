# Build pipeline: containerization-challenge-furnace-records

The application's code is on GitHub: copy the files of `github` into the root of the application's repository (the folders mirror the repository), commit them on a branch and open a pull request. The `README.md` in its `containerizer/` folder says which secrets or variables to create first.

Or make them as a patch (`git am`) from a checkout with `containerizer pipeline <path> --patch`.

More: https://containerizer.eu/build-pipelines/
